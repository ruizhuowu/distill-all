# 会计学原理 - 核心知识点总结

## 一、会计基础概念

### 1. 会计等式（★★★）
```
资产 = 负债 + 所有者权益
(Assets = Liabilities + Owner's Equity)
```
**这是试算平衡的理论依据！**

### 2. 会计要素
| 要素 | 定义 | 特点 |
|------|------|------|
| **资产** | 企业拥有或控制的经济资源 | 预期带来经济利益 |
| **负债** | 企业承担的现时义务 | 预期导致经济利益流出 |
| **所有者权益** | 资产扣除负债后的余额 | 剩余索取权 |
| **收入** | 经济利益的总流入 | 日常活动形成 |
| **费用** | 经济利益的总流出 | 日常活动形成 |
| **利润** | 收入减去费用后的净额 | 经营成果 |

### 3. 会计科目 vs 会计账户
- **科目**：对会计要素的细分，是**名称**
- **账户**：根据科目开设的，有**结构**（借方、贷方、余额）
- 口诀：科目是名称，账户有结构

---

## 二、借贷记账法（★★★核心）

### 1. 基本定义
以 **"借"** 和 **"贷"** 作为记账符号的**复式记账法**

> ⚠️ "借""贷"仅为记账符号，无实际汉字含义

### 2. 账户基本结构
```
┌─────────────┬─────────────┐
│    借方     │    贷方     │
│   （左方）   │   （右方）   │
└─────────────┴─────────────┘
```
**口诀：左借右贷**

### 3. 各类账户借贷方向规律（必背）★★★

| 账户类型 | 借方 | 贷方 | 余额方向 |
|---------|------|------|---------|
| **资产类** ★★★ | 增加 ✓ | 减少 | 借方 |
| **成本类** | 增加 ✓ | 减少 | 借方 |
| **费用类** | 增加 ✓ | 减少 | 一般无余额 |
| **负债类** ★★★ | 减少 | 增加 ✓ | 贷方 |
| **所有者权益类** ★★★ | 减少 | 增加 ✓ | 贷方 |
| **收入类** | 减少 | 增加 ✓ | 一般无余额 |

**记忆口诀**：
> 资成费，借增贷减；
> 负所收，贷增借减。

### 4. 记账规则（八字真言）★★★
> ## **有借必有贷，借贷必相等**

## 三、会计分录（核心技能）★★★

### 1. 定义
简称**分录**，是对每项经济业务列示**应借、应贷账户名称及其金额**的记录

### 2. 三要素
| 要素 | 说明 |
|------|------|
| **应借应贷方向** | 确定借方或贷方 |
| **相互对应的科目** | 会计科目名称 |
| **金额** | 具体数字 |

### 3. 分类
| 类型 | 格式 |
|------|------|
| **简单分录** | 一借一贷 |
| **复合分录** | 一借多贷 / 多借一贷 |

⚠️ 禁止将无联系的简单分录合并为多借多贷！

### 4. 编制步骤（3步法）
```
步骤1: 看增减 → 判断会计要素增减变化
步骤2: 找科目 → 匹配对应会计科目  
步骤3: 定方向 → 确定借贷方向
```

### 5. 书写格式示例
```
借：银行存款　　　　100,000
    贷：实收资本　　　　　　100,000
```

## 四、常用会计科目表

### 资产类
| 流动资产 | 非流动资产 |
|---------|-----------|
| 库存现金、银行存款 | 长期股权投资 |
| 应收账款、预付账款 | 固定资产、在建工程 |
| 原材料、库存商品 | 无形资产 |

### 负债类
| 流动负债 | 非流动负债 |
|---------|-----------|
| 短期借款 | 长期借款 |
| 应付账款、应付职工薪酬 | 应付债券 |
| 应交税费 | |

### 所有者权益类
实收资本（股本）、资本公积、盈余公积、未分配利润

### 损益类
| 收入类 | 费用类 |
|--------|--------|
| 主营业务收入 | 主营业务成本 |
| 其他业务收入 | 销售费用、管理费用 |
| 营业外收入 | 财务费用 |

## 五、试算平衡

### 1. 平衡公式
| 平衡类型 | 公式 | 理论依据 |
|---------|------|---------|
| **发生额平衡** | 借方发生额合计 = 贷方发生额合计 | 有借必有贷，借贷必相等 |
| **余额平衡** | 借方余额合计 = 贷方余额合计 | 资产=负债+所有者权益 |

### 2. 关键提示 ⚠️
| 情况 | 结论 |
|------|------|
| 试算**不平衡** | → 记账**一定有错误** ✗ |
| 试算**平衡** | → **不能表明**一定正确！|

**常见不影响平衡的错误**：
- 漏记某项业务
- 重记某项业务
- 科目用错但金额正确
- 借贷方向同时颠倒

## 六、典型业务分录示例

### 1. 投资者投入资金
```
借：银行存款
    贷：实收资本
```

### 2. 购买材料（款未付）
```
借：原材料
    应交税费—应交增值税（进项税额）
    贷：应付账款
```

### 3. 销售商品（款未收）
```
借：应收账款
    贷：主营业务收入
        应交税费—应交增值税（销项税额）
```

### 4. 计提折旧
```
借：管理费用/制造费用
    贷：累计折旧
```

### 5. 结转本年利润
```
借：主营业务收入
    贷：本年利润
    
借：本年利润
    贷：主营业务成本
        管理费用
        销售费用
```
