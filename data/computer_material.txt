# 计算机应用基础 - 期末重点考点汇总

## 第一章 计算机基础知识 ★★★

### 1. 发展历史
- **阶段**：手工 → 机械 → 电子
- **第一台电子计算机**：1946年美国 **ENIAC**（缺点：十进制、不能存储程序）
- **冯·诺依曼**：提出"存储程序"思想和**二进制**，被称为计算机之父

### 2. 四代划分（按元器件）
| 代次 | 元器件 | 时间 |
|------|--------|------|
| 第一代 | 电子管 | 1946-1957 |
| 第二代 | 晶体管 | 1958-1964 |
| 第三代 | 集成电路 | 1965-1970 |
| 第四代 | 大规模/超大规模集成电路 | 1971至今 |

### 3. 计算机特点
速度快、精度高、逻辑性强、自动化程度高、通用性强

### 4. 系统组成

#### 硬件五大部分
运算器、控制器、存储器、输入设备、输出设备

#### CPU组成
由**运算器（ALU）**和**控制器**组成
性能指标：主频、字长、外频等

#### 存储器分类
| 类型 | 特点 |
|------|------|
| RAM（随机存取） | 易失性，断电丢失 |
| ROM（只读） | 非易失性，断电不丢 |
| Cache（高速缓冲） | 速度最快，容量最小 |
| 硬盘（外存） | 容量大，速度慢 |

#### 存储单位换算
1B = 8bit
1KB = 1024B
1MB = 1024KB
1GB = 1024MB

#### 常见接口
- **USB**：热插拔
- **VGA**：显示器接口
- **RJ-45**：网口
- **PS/2**：键盘鼠标（旧）

### 5. 软件系统
- **系统软件**：OS、语言处理程序、数据库管理系统
- **应用软件**：办公软件、游戏等

### 6. 数制与编码
- **ASCII码**：7位，128个字符（A=65，a=97，0=48）
- **汉字编码**：输入码、机内码、字形码
- **二进制转换**：
  - 二→十：按权展开
  - 十→二：整数除2取余，小数乘2取整

## 第二章 Windows 操作系统 ★★

### 1. 桌面组成
图标、任务栏、"开始"按钮

### 2. 文件管理（重点）
- **命名规则**：最长255字符，不能包含 `\ / : * ? " < > |`
- **选取操作**：
  - Shift+点击 → 连续选取
  - Ctrl+点击 → 不连续选取
- **剪贴板**：内存中的一块区域，临时存放复制/剪切的内容
- **删除操作**：
  - Delete键 → 进回收站
  - Shift+Delete → 彻底删除

### 3. 快捷键
| 快捷键 | 功能 |
|--------|------|
| Ctrl+C/V/X | 复制/粘贴/剪切 |
| Ctrl+Z | 撤销 |
| Alt+F4 | 关闭窗口 |
| Ctrl+A | 全选 |
| Win+E | 打开资源管理器 |
| Win+D | 显示桌面 |

## 第四章 Excel 报表软件 ★★★

### 1. 基本概念
- **工作簿**：文件（.xlsx）
- **工作表**：Sheet1, Sheet2...
- **单元格**：列标+行号（如 A1）

### 2. 引用方式（核心难点）★★★
| 引用类型 | 格式 | 复制时变化 |
|---------|------|-----------|
| **相对引用** | A1 | 自动变化 |
| **绝对引用** | $A$1 | 不变（加$锁定）|
| **混合引用** | $A1 或 A$1 | 行或列一个变 |

### 3. 常用函数 ★★★
| 函数 | 功能 | 示例 |
|------|------|------|
| SUM | 求和 | =SUM(A1:A10) |
| AVERAGE | 平均值 | =AVERAGE(A1:A10) |
| MAX/MIN | 最大/最小 | =MAX(A1:A10) |
| IF | 条件判断 | =IF(A1>60,"及格","不及格") |
| RANK | 排名 | =RANK(A1,$A$1:$A$10) |
| COUNT/COUNTIF | 计数 | =COUNTIF(A1:A10,">60") |
| VLOOKUP | 查找 | =VLOOKUP(值,区域,列号,0) |

### 4. 数据分析
- **排序**：升序/降序
- **筛选**：自动筛选/高级筛选
- **分类汇总**：使用前必须先按分类字段排序！

### 5. 图表制作
柱状图、折线图、饼图、散点图

## 第七章 互联网应用基础 ★★

### 1. 网络基础
- **起源**：ARPANET
- **协议**：TCP/IP协议族
  - 应用层（HTTP, FTP, SMTP）
  - 传输层（TCP, UDP）
  - 网络层（IP）
  - 网络接口层

### 2. IP地址
- **IPv4**：32位，点分十进制（192.168.1.1）
- **IPv6**：128位
- **私有地址**：192.168.x.x / 10.x.x.x / 172.16-31.x.x

### 3. 域名系统（DNS）
将域名解析为IP地址

### 4. 应用服务
| 服务 | 协议 | 端口 |
|------|------|------|
| WWW（网页） | HTTP | 80 |
| Email发送 | SMTP | 25 |
| Email接收 | POP3 | 110 |
| Email接收 | IMAP | 143 |
| 文件传输 | FTP | 20/21 |

### 5. 网络安全
| 威胁 | 特点 |
|------|------|
| 病毒 | 寄生在其他程序中 |
| 蠕虫 | 独立传播 |
| 木马 | 远程控制 |

**防护措施**：安装杀毒软件、使用防火墙、数据备份、定期更新系统
